# Dynamic Video Ads Example Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `plainly-dynamic-video-ads/`, an example app where one ad (product, headline, offer, price, CTA) is rendered in 16:9, 9:16 and 1:1 with three single Plainly render calls, then shown side by side.

**Architecture:** TanStack Start app copied from the `plainly-batch-render` skeleton. Server functions in `src/lib/plainly.ts` read the project's templates (one per aspect ratio, matched by resolution), fan out three `POST /renders` calls tagged with custom attributes, and find renders again with `POST /renders/attributes`. All pure logic (validation, parameter mapping, template matching, grouping, newest-render selection) lives in `src/lib/ad.ts` and is unit tested. No database, no webhooks, no localStorage.

**Tech Stack:** TanStack Start 1.168, React 19, TypeScript 6, Tailwind CSS 4, shadcn/ui (base-nova), Biome 2.5, Vitest 5, pnpm 12, Node 24.

**Spec:** `docs/superpowers/specs/2026-10-15-dynamic-video-ads-design.md`

## Global Constraints

- Folder: `plainly-dynamic-video-ads/` at repo root. Package name `plainly-dynamic-video-ads`.
- Dependencies: exactly the versions in `plainly-batch-render/package.json`. Add no new npm dependencies (shadcn `input` and `label` components are generated source files, not dependencies).
- Environment: only `PLAINLY_API_KEY` and `PLAINLY_PROJECT_ID`. No template IDs in env.
- API base: `https://api.plainlyvideos.com/api/v2`, Basic auth with the API key as username and empty password, only from server code.
- Every render gets attributes `{ example: "dynamic-video-ads", adId, format }`; `example` is a string.
- Formats are exactly `"16:9"`, `"9:16"`, `"1:1"`, in that order.
- Placeholder parameter names: `plainlyEditHeadline`, `plainlyEditOffer`, `plainlyEditPrice`, `plainlyEditOldPrice`, `plainlyEditCta`, `plainlyEditImage`. Only `toParameters`/`fromParameters` in `src/lib/ad.ts` may mention them.
- Length limits: headline 40, offer 15, price 10, old price 10, call to action 15. Old price is the only optional field.
- Attribute filters always use the default `full` response model.
- Polling interval 5 seconds, next poll scheduled after the previous one settles.
- Code style: match `plainly-batch-render` (short comments explaining *why*, Biome formatting, `@/` imports).
- Commit messages: Conventional Commits, ending with the line `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- All commands run from `plainly-dynamic-video-ads/` unless stated otherwise.

## Review Focus

1. A hand-crafted request with whitespace-only, non-string or oversized fields, or a product id like `toString`, must be rejected with a readable message, not rendered. Pinned in Task 3 (`pickAd` tests).
2. A retried format has an old failed render and a new one, and the API sort order is undocumented: the newest render by `createdDate` must win regardless of order. Pinned in Task 4 (`latestPerFormat` tests).
3. A project with extra templates, odd resolutions, two templates of the same ratio, or a missing ratio: first match wins, missing ratio names the format. Pinned in Task 3 (`templatesByFormat` tests).
4. `/ad/..`, `/ad/abc` or any non-UUID must show "Ad not found" without calling the API. Pinned in Task 4 (`isAdId` tests).
5. Renders in the same org with `attributes: null`, no `adId`, or an unknown `format` must be ignored by grouping and selection. Pinned in Task 4 (`latestPerFormat`, `groupAds` tests).

```js
// Throwaway probe, not committed. Run: node --env-file=.env probe.mjs
const API = "https://api.plainlyvideos.com/api/v2";
const auth = `Basic ${btoa(`${process.env.PLAINLY_API_KEY}:`)}`;

async function call(path, init) {
  const res = await fetch(`${API}${path}`, {
    ...init,
    headers: { "Content-Type": "application/json", Authorization: auth },
  });
  const text = await res.text();
  if (!res.ok) throw new Error(`${path} ${res.status} ${text}`);
  return text ? JSON.parse(text) : null;
}

const filter = (key, value) =>
  call("/renders/attributes?size=50", {
    method: "POST",
    body: JSON.stringify({ filters: [{ key, value }] }),
  });

const project = await call(`/projects/${process.env.PLAINLY_PROJECT_ID}`);
console.log(
  "templates:",
  project.templates.map((t) => ({ id: t.id, name: t.name, resolution: t.resolution })),
);

const adId = crypto.randomUUID();
const created = [];
for (const format of ["first", "second"]) {
  const render = await call("/renders", {
    method: "POST",
    body: JSON.stringify({
      projectId: project.id,
      templateId: project.templates[0].id,
      parameters: {},
      attributes: { example: "dynamic-video-ads-probe", adId, format },
    }),
  });
  created.push(render.id);
  await new Promise((r) => setTimeout(r, 1500));
}

const now = await filter("adId", adId);
console.log("visible immediately:", now.length, "of", created.length);
console.log("order immediately:", now.map((r) => [r.attributes.format, r.createdDate]));

await new Promise((r) => setTimeout(r, 5000));
const later = await filter("adId", adId);
console.log("visible after 5s:", later.length, "of", created.length);
console.log("order after 5s:", later.map((r) => [r.attributes.format, r.createdDate]));

for (const id of created) {
  try {
    await call(`/renders/${id}/cancel`, { method: "POST" });
  } catch (err) {
    console.log("cancel failed (render may be finished already):", err.message);
  }
}
```

- [ ] **Step 2: Write the failing tests `src/lib/ad.test.ts`**

import { expect, test } from "vitest";
import {
  adFor,
  formatOf,
  fromParameters,
  pickAd,
  renderBody,
  templatesByFormat,
  toParameters,
} from "@/lib/ad";

const valid = {
  productId: "sneakers",
  headline: "Run further. Recover faster.",
  offer: "20% OFF",
  price: "$79",
  oldPrice: "$99",
  cta: "Shop now",

test("formatOf maps resolutions to aspect ratios", () => {
  expect(formatOf({ width: 1920, height: 1080 })).toBe("16:9");
  expect(formatOf({ width: 1080, height: 1920 })).toBe("9:16");
  expect(formatOf({ width: 1080, height: 1080 })).toBe("1:1");
  // Not exactly 16:9, but close enough to be used as one
  expect(formatOf({ width: 1366, height: 768 })).toBe("16:9");
  expect(formatOf({ width: 800, height: 600 })).toBeUndefined();
  expect(formatOf({ width: 1920, height: 0 })).toBeUndefined();
  expect(formatOf(undefined)).toBeUndefined();
});

test("templatesByFormat picks the first template per format", () => {
  expect(
    templatesByFormat([
      { id: "wide", resolution: { width: 1920, height: 1080 } },
      { id: "wide-4k", resolution: { width: 3840, height: 2160 } },
      { id: "no-resolution" },
      { id: "tall", resolution: { width: 1080, height: 1920 } },
      { id: "old-tv", resolution: { width: 800, height: 600 } },
      { id: "square", resolution: { width: 1080, height: 1080 } },
    ]),
  ).toEqual({ "16:9": "wide", "9:16": "tall", "1:1": "square" });
});

test("templatesByFormat names the missing format", () => {
  expect(() =>
    templatesByFormat([
      { id: "wide", resolution: { width: 1920, height: 1080 } },
      { id: "square", resolution: { width: 1080, height: 1080 } },
    ]),
  ).toThrow("Project has no 9:16 template");
  expect(() => templatesByFormat([])).toThrow("Project has no 16:9 template");
});

test("adFor fills an ad with the product's copy", () => {

});

test("pickAd trims fields and allows an empty old price", () => {

test("pickAd rejects unknown products", () => {

export const FORMATS = ["16:9", "9:16", "1:1"] as const;
export type Format = (typeof FORMATS)[number];

export const isFormat = (value: unknown): value is Format =>
  FORMATS.includes(value as Format);

// Width divided by height
const RATIOS: Record<Format, number> = {
  "16:9": 16 / 9,
  "9:16": 9 / 16,
  "1:1": 1,
};

export function formatOf(resolution?: {
  width?: number;
  height?: number;
}): Format | undefined {
  if (!resolution?.width || !resolution?.height) return undefined;
  const ratio = resolution.width / resolution.height;
  // Small tolerance, so sizes like 1366x768 still count as 16:9
  return FORMATS.find((format) => Math.abs(RATIOS[format] - ratio) < 0.01);
}

export type Template = {
  id: string;
  resolution?: { width?: number; height?: number };
};

// One template per format, matched by the size of its rendered composition.
// The first match wins, other templates in the project are ignored.
export function templatesByFormat(
  templates: Template[],
): Record<Format, string> {
  const found: Partial<Record<Format, string>> = {};
  for (const template of templates) {
    const format = formatOf(template.resolution);
    if (format && !found[format]) found[format] = template.id;
  }
  for (const format of FORMATS) {
    if (!found[format]) throw new Error(`Project has no ${format} template`);
  }
  return found as Record<Format, string>;
}

// Subset of the render object returned by the Plainly API
export type Render = {
  id: string;
  state: string;
  createdDate: string;
  // null when the render was created without custom attributes
  attributes: { adId?: string; format?: string } | null;
  // This example only sends text parameters
  parameters?: Record<string, string>;
  output?: string;
  thumbnailUris?: string[];
  expired?: boolean;
  error?: { message?: string };
};

const IN_PROGRESS_STATES = ["PENDING", "THROTTLED", "QUEUED", "IN_PROGRESS"];

// Anything else (DONE, INVALID, FAILED, CANCELLED) is final
export const isFinished = (render: Pick<Render, "state">) =>
  !IN_PROGRESS_STATES.includes(render.state);

// IN_PROGRESS -> "In progress", for people instead of the API
export const stateLabel = (state: string) =>
  state.charAt(0) + state.slice(1).toLowerCase().replaceAll("_", " ");

// Ad ids are UUIDs, anything else never reaches the API
export const isAdId = (id: unknown): id is string =>
  typeof id === "string" &&
  /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i.test(id);

// A retry adds a new render with the same attributes, and the API's sort
// order is not documented, so compare createdDate ourselves
export function latestPerFormat(
  renders: Render[],
): Partial<Record<Format, Render>> {
  const latest: Partial<Record<Format, Render>> = {};
  for (const render of renders) {
    const format = render.attributes?.format;
    if (!isFormat(format)) continue;
    const current = latest[format];
    if (
      !current ||
      Date.parse(render.createdDate) > Date.parse(current.createdDate)
    ) {
      latest[format] = render;
    }
  }
  return latest;
}

// Formats that were never created have nothing to wait for
export const isAdFinished = (renders: Render[]) => {
  const latest = latestPerFormat(renders);
  return FORMATS.every((format) => {
    const render = latest[format];
    return !render || isFinished(render);
  });
};

export type AdSummary = {
  adId: string;
  createdDate: string;
  ad: Ad;
  done: number;
  failed: number;
  rendering: number;
};

export function groupAds(renders: Render[]): AdSummary[] {
  const byAd = new Map<string, Render[]>();
  for (const render of renders) {
    const adId = render.attributes?.adId;
    if (!isAdId(adId)) continue;
    byAd.set(adId, [...(byAd.get(adId) ?? []), render]);
  }

  return [...byAd]
    .map(([adId, group]) => {
      const latest = latestPerFormat(group);
      const present = FORMATS.flatMap((format) => latest[format] ?? []);
      const done = present.filter((render) => render.state === "DONE").length;
      const rendering = present.filter((render) => !isFinished(render)).length;
      return {
        adId,
        // The first render marks when the ad was created, retries come later
        createdDate: group.reduce(
          (first, render) =>
            Date.parse(render.createdDate) < Date.parse(first)
              ? render.createdDate
              : first,
          group[0].createdDate,
        ),
        ad: fromParameters(group.find((r) => r.parameters)?.parameters ?? {}),
        done,
        rendering,
        // Failed, invalid, cancelled and never created formats
        failed: FORMATS.length - done - rendering,
      };
    })
    .sort((a, b) => Date.parse(b.createdDate) - Date.parse(a.createdDate));
}

export function adStatus({
  done,
  failed,
  rendering,
}: Pick<AdSummary, "done" | "failed" | "rendering">) {
  if (rendering > 0) return { label: "Rendering", tone: "rendering" } as const;
  if (failed > 0) return { label: `${failed} failed`, tone: "failed" } as const;
  return { label: `${done}/${FORMATS.length} done`, tone: "done" } as const;
}

    const apiKey = process.env.PLAINLY_API_KEY;

  const text = await res.text();

  try {
    message = JSON.parse(text).message ?? text;

}

    );

  if (!res.ok) throw await apiError(res);
  const project: { templates?: Template[] } = await res.json();
  return templatesByFormat(project.templates ?? []);
});

      body: JSON.stringify(body),
    });
    if (!res.ok) throw await apiError(res);
  },
);

    const res = await plainlyFetch(`/renders/attributes?size=${size}`, {
      method: "POST",

    });
    if (!res.ok) throw await apiError(res);
    const renders: Render[] = await res.json();
    return renders;
  },

export const createAd = createServerFn({ method: "POST" })
  .validator((ad: Ad) => pickAd(ad))
  .handler(async ({ data: ad }) => {
    const projectId = getProjectId();
    const templates = await getTemplates(projectId);
    const adId = crypto.randomUUID();
    const parameters = toParameters(ad);

    // Renders are independent: one format can fail while the others are created
    const results = await Promise.allSettled(
      FORMATS.map((format) =>
        createRender(
          renderBody({
            projectId,
            templateId: templates[format],
            adId,
            format,
            parameters,
          }),
        ),
      ),
    );

    const failed = results.filter(
      (result): result is PromiseRejectedResult => result.status === "rejected",
    );
    // Nothing was created, so there is no ad page to show
    if (failed.length === FORMATS.length) throw failed[0].reason;

    return { adId };
  });

// Renders one format of an existing ad again
export const retryFormat = createServerFn({ method: "POST" })
  .validator((input: { adId: string; format: Format }) => {
    if (!isAdId(input?.adId) || !isFormat(input?.format)) {
      throw new Error("Invalid retry request");
    }
    return { adId: input.adId, format: input.format };
  })
  .handler(async ({ data: { adId, format } }) => {
    const projectId = getProjectId();
    // Every render of an ad has the same parameters, copy them from any of them
    const renders = await filterRenders("adId", adId, 50);
    const parameters = renders.find((render) => render.parameters)?.parameters;
    if (!parameters) throw new Error("Ad not found");

    const templates = await getTemplates(projectId);
    // Same attributes as the first try, so the new render replaces the old one
    await createRender(
      renderBody({
        projectId,
        templateId: templates[format],
        adId,
        format,
        parameters,
      }),
    );
  });

// Every render of one ad, including retries
export const getAdRenders = createServerFn({ method: "GET" })
  .validator((adId: string) => {
    // Rejects ids like ".." before they reach the API

  .handler(async ({ data: adId }) => {
    // Three formats plus retries, 50 leaves plenty of room
    const renders = await filterRenders("adId", adId, 50);
    if (renders.length === 0) throw notFound();

export function RenderBadge({ render }: { render?: Render }) {
  if (!render) return <Badge variant="destructive">Not created</Badge>;
  if (render.state === "DONE") return <Badge>Done</Badge>;
  return (
    <Badge variant={isFinished(render) ? "destructive" : "secondary"}>
      {stateLabel(render.state)}
    </Badge>

export function RenderFrame({
  render,
  retrying,
  onRetry,
}: {
  render?: Render;
  retrying: boolean;
  onRetry: () => void;
}) {
  if (render?.state === "DONE" && render.expired) {
    return <p className="text-sm text-muted-foreground">Output expired</p>;
  }
  if (render?.state === "DONE" && render.output) {
    return (
      // biome-ignore lint/a11y/useMediaCaption: generated ad video has no captions
      <video
        src={render.output}
        poster={render.thumbnailUris?.[0]}
        controls
        preload="metadata"
        className="size-full object-cover"
      />
    );
  }
  if (render?.state === "DONE") {
    return <p className="text-sm text-muted-foreground">No preview</p>;
  }
  if (render && !isFinished(render)) {
    return (
      <LoaderCircle
        role="status"
        aria-label="Rendering"
        className="size-6 animate-spin text-muted-foreground"
      />
    );
  }

  // Failed, invalid, cancelled, or the create call failed
  return (
    <div className="grid justify-items-center gap-2 p-3 text-center">
      <p className="text-sm text-destructive">
        {render ? "Render failed" : "Not created"}
      </p>
      {render?.error?.message && (
        <p className="line-clamp-3 text-xs text-muted-foreground">
          {render.error.message}
        </p>

import {
  createFileRoute,
  type ErrorComponentProps,
  Link,
  useRouter,
} from "@tanstack/react-router";
import { useServerFn } from "@tanstack/react-start";
import { useEffect, useState } from "react";
import { AdEditor } from "@/components/ad-editor";
import { AdFrames } from "@/components/ad-frames";
import { RenderBadge, RenderFrame } from "@/components/render-frame";
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";
import { Button } from "@/components/ui/button";
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";
import {
  FORMATS,
  type Format,
  fromParameters,
  isAdFinished,
  latestPerFormat,
  type Render,
} from "@/lib/ad";
import { getAdRenders, retryFormat } from "@/lib/plainly";

const POLL_INTERVAL_MS = 5000;

export const Route = createFileRoute("/ad/$adId")({
  loader: ({ params }) => getAdRenders({ data: params.adId }),
  component: AdPage,
  errorComponent: AdError,
  notFoundComponent: AdNotFound,
});

function AdPage() {
  const renders = Route.useLoaderData();
  const { adId } = Route.useParams();

  return <AdRenders key={adId} adId={adId} initial={renders} />;
}

// Polls the ad until every format is finished. Polling happens here instead of
// re-running the route loader, so a failed poll keeps the last renders on screen
// instead of swapping them for the error component.
function AdRenders({ adId, initial }: { adId: string; initial: Render[] }) {
  const [renders, setRenders] = useState(initial);
  const [pollFailed, setPollFailed] = useState(false);
  const [retrying, setRetrying] = useState<Format>();
  const [retryError, setRetryError] = useState<string>();
  const retryFormatFn = useServerFn(retryFormat);
  const router = useRouter();

  useEffect(() => {
    // The loader runs again after a retry, start over from its data
    setRenders(initial);
    if (isAdFinished(initial)) return;
    let active = true;
    let timer: ReturnType<typeof setTimeout>;

    // The next poll is scheduled only after the previous one settles,
    // so slow responses never overlap or cancel each other
    const poll = async () => {
      try {
        const next = await getAdRenders({ data: adId });
        if (!active) return;
        setRenders(next);
        setPollFailed(false);
        if (isAdFinished(next)) {
          // Refreshes the loaders, so other views see the final states
          router.invalidate();
          return;
        }
      } catch {
        if (!active) return;
        setPollFailed(true);
      }
      timer = setTimeout(poll, POLL_INTERVAL_MS);
    };
    timer = setTimeout(poll, POLL_INTERVAL_MS);

    return () => {
      active = false;
      clearTimeout(timer);
    };
  }, [adId, initial, router]);

  const retry = async (format: Format) => {
    setRetrying(format);
    setRetryError(undefined);
    try {
      await retryFormatFn({ data: { adId, format } });
      // Reloads the renders, which also restarts polling
      await router.invalidate();
    } catch (err) {
      setRetryError(err instanceof Error ? err.message : String(err));
    } finally {
      setRetrying(undefined);
    }
  };

  const latest = latestPerFormat(renders);
  const done = FORMATS.filter((f) => latest[f]?.state === "DONE").length;
  // The form starts from the ad's own values, submitting creates a new ad
  const ad = fromParameters(
    initial.find((render) => render.parameters)?.parameters ?? {},
  );

  return (
    <AdEditor
      initial={ad}
      aside={() => (
        <Card>
          <CardHeader>
            <CardTitle>Renders</CardTitle>
            <CardDescription>
              {done} of {FORMATS.length} formats done · ad{" "}
              <code>{adId.slice(0, 8)}</code>
            </CardDescription>
          </CardHeader>
          <CardContent className="grid gap-4">
            {pollFailed && (
              <Alert>
                <AlertTitle>Could not refresh renders</AlertTitle>
                <AlertDescription>Retrying in a few seconds.</AlertDescription>
              </Alert>
            )}
            {retryError && (
              <Alert variant="destructive">
                <AlertTitle>Retry failed</AlertTitle>
                <AlertDescription>{retryError}</AlertDescription>
              </Alert>
            )}
            <AdFrames
              badge={(format) => <RenderBadge render={latest[format]} />}
              frame={(format) => (
                <RenderFrame
                  render={latest[format]}
                  retrying={retrying === format}
                  onRetry={() => retry(format)}
                />
              )}
            />
          </CardContent>
        </Card>
      )}
    />
  );
}

function AdError({ error }: ErrorComponentProps) {
  const router = useRouter();
  return (
    <Alert variant="destructive">
      <AlertTitle>Could not load ad</AlertTitle>
      <AlertDescription className="grid gap-2">
        {error instanceof Error ? error.message : String(error)}
        <Button
          variant="outline"
          size="sm"
          className="w-fit"
          onClick={() => router.invalidate()}
        >
          Retry
        </Button>
      </AlertDescription>
    </Alert>
  );
}

function AdNotFound() {
  return (
    <Alert>
      <AlertTitle>Ad not found</AlertTitle>
      <AlertDescription>
        <Link to="/" className="underline">
          Create a new ad
        </Link>
      </AlertDescription>
    </Alert>
  );
}

      <CardHeader>
        <CardTitle>Recent ads</CardTitle>
        <CardDescription>
          Found with the <code>example = {EXAMPLE}</code> attribute filter.
        </CardDescription>
      </CardHeader>
      <CardContent className="max-h-96 overflow-y-auto">
        {error ? (
          <Alert variant="destructive">
            <AlertTitle>Could not load recent ads</AlertTitle>
            <AlertDescription>{error}</AlertDescription>
          </Alert>
        ) : ads.length === 0 ? (
          <Empty>
            <EmptyHeader>
              <EmptyMedia variant="icon">
                <Clapperboard />
              </EmptyMedia>
              <EmptyTitle>No ads yet</EmptyTitle>
              <EmptyDescription>
                Render an ad above, it will show up here.
              </EmptyDescription>
            </EmptyHeader>
          </Empty>
        ) : (
          <ItemGroup className="grid gap-2 sm:grid-cols-2 lg:grid-cols-3">
            {ads.map((summary) => (
              <AdItem key={summary.adId} summary={summary} />
            ))}
          </ItemGroup>
        )}
      </CardContent>
    </Card>
  );
}

function AdItem({ summary }: { summary: AdSummary }) {
  const status = adStatus(summary);

  return (
    <Item
      variant="outline"
      size="sm"
      // The router marks the link of the ad on screen with data-status="active"
      className="data-[status=active]:border-primary data-[status=active]:bg-muted"
      render={<Link to="/ad/$adId" params={{ adId: summary.adId }} />}
    >
      <ItemMedia variant="image">
        <img src={products[summary.ad.productId].image} alt="" />
      </ItemMedia>
      <ItemContent className="min-w-0">
        <ItemTitle className="line-clamp-1">{summary.ad.headline}</ItemTitle>
        {/* Server and browser can format dates in different time zones */}
        <ItemDescription suppressHydrationWarning>
          {formatDate(summary.createdDate)}
        </ItemDescription>
      </ItemContent>
      <ItemActions>
        <Badge variant={BADGE_VARIANT[status.tone]}>{status.label}</Badge>
      </ItemActions>
    </Item>
  );
}

# Dynamic video ads example

This example demonstrates dynamic creative for video advertising with [Plainly Videos](https://www.plainlyvideos.com/): one After Effects template produces many ad variants with different headlines, offers, prices and product images, and every variant renders in 16:9, 9:16 and 1:1, ready for each ad platform.

## What this App does?

**Non-technical view:**
Pick a product, adjust the headline, offer, price and call to action, and watch a live preview in all three formats. Click one button and get the same ad as a wide, a tall and a square video.

**Technical view:**
A TanStack Start app that reads the project's templates from `GET /api/v2/projects/{projectId}`, picks one template per aspect ratio by its resolution, and sends three `POST /api/v2/renders` requests to `https://api.plainlyvideos.com`, one per format. Every render is tagged with custom attributes, and the app finds them again with `POST /api/v2/renders/attributes`. No database, no webhooks and no local storage are needed.

## What you'll learn

- **🎯 One ad, many formats**: Fan out one set of parameters to one render per aspect ratio.
- **🧩 Template discovery**: Find the right template for each format from the project, instead of configuring template ids.
- **🏷️ Attribute filtering**: Tag renders with your own data and query them later, for both a single ad and a list of recent ads.
- **🔁 Per-render retry**: Renders are independent, so one format can fail and be retried on its own.
- **🔐 Server functions**: Keep your Plainly Videos API key on the server with TanStack Start server functions.

### Find the template for each format

Template ids are not configured. The app reads the project and matches each template to a format by the size of its rendered composition:

```ts
// ./src/lib/ad.ts
export function templatesByFormat(
  templates: Template[],
): Record<Format, string> {
  const found: Partial<Record<Format, string>> = {};
  for (const template of templates) {
    const format = formatOf(template.resolution);
    if (format && !found[format]) found[format] = template.id;
  }
  for (const format of FORMATS) {
    if (!found[format]) throw new Error(`Project has no ${format} template`);
  }
  return found as Record<Format, string>;
}
```

### Render one ad in three formats

The `createAd` server function sends three single render requests with the same parameters and a different template. `Promise.allSettled` lets one format fail without losing the others:

```ts
// ./src/lib/plainly.ts
const results = await Promise.allSettled(
  FORMATS.map((format) =>
    createRender(
      renderBody({
        projectId,
        templateId: templates[format],
        adId,
        format,
        parameters,
      }),
    ),
  ),
);
```

Every request carries custom attributes. Plainly stores them on the render, which is how the app finds it again:

### Find renders by attribute

`POST /api/v2/renders/attributes` returns the renders whose attributes match. The ad page filters by `adId`, the recent ads list filters by `example`:

```ts
// ./src/lib/plainly.ts
const res = await plainlyFetch(`/renders/attributes?size=${size}`, {
  method: "POST",
  body: JSON.stringify({ filters: [{ key, value }] }),
});
```

While any format is still rendering, the ad page calls this again every 5 seconds.

### Retry one format

A retry creates a new render with the same parameters and attributes. An ad can now have two renders for one format, so the app always shows the newest one:

```ts
// ./src/lib/ad.ts
export function latestPerFormat(
  renders: Render[],
): Partial<Record<Format, Render>> {
  const latest: Partial<Record<Format, Render>> = {};
  for (const render of renders) {
    const format = render.attributes?.format;
    if (!isFormat(format)) continue;
    const current = latest[format];
    if (
      !current ||
      Date.parse(render.createdDate) > Date.parse(current.createdDate)
    ) {
      latest[format] = render;
    }
  }
  return latest;
}
```

### Good to know
